# Ark-X LMS Enhancer

![Extension Icon](https://raw.githubusercontent.com/shadowofleaf96/Ark-X-LMS-Enhancer/23e0a1835ea67fcf66cf51eeb0db2dd784aa6cae/images/icon48.png)

## Overview
Ark-X LMS Enhancer is a Chrome extension designed to enhance the Ark-X Learning Platform with various feature requests and improvements. The extension aims to provide a better user experience by implementing requested features such as Dark Mode and AutoScroll to Course in the menu, among other enhancements.

## Features
- **Dark Mode**: Toggle between light and dark themes for better readability and reduced eye strain.
- **AutoScroll to Course**: Automatically scroll to the selected course in the menu for quick navigation.
- **Custom Enhancements**: Additional features to improve the overall functionality and usability of the Ark-X Learning Platform.

## Installation
To install the Ark-X LMS Enhancer, follow these steps:
1. Download the extension files from the repository.
2. Open Google Chrome and navigate to `chrome://extensions`.
3. Enable 'Developer mode' by toggling the switch in the top right corner.
4. Click the 'Load unpacked' button and select the directory containing the extension files.

## Usage
Once installed, the Ark-X LMS Enhancer will automatically apply its enhancements to the Ark-X Learning Platform. You can access the extension's settings and toggle features through the extension's popup interface.

## Compatibility
The Ark-X LMS Enhancer is compatible with the following URLs:
- `https://arkx.academy/*`
- `https://arkx-academy.gitbook.io/*`
- `https://cdn.mycourse.app/*`

## Permissions
The extension requires the following permissions:
- `activeTab`: Allows the extension to read and modify the active tab.
- `tabs`: Allows the extension to interact with the browser tabs.
- `scripting`: Allows the extension to execute scripts in the context of web pages.
